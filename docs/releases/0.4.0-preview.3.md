# Elka MIDI Pickup 0.4.0-preview.3

**Local beta build for testing. Not published to GitHub.**

- Application MIDI Control now shows only VAIO, AUX and VAIO 3 as supported by the connected VoiceMeeter edition. The In 1–5 pages are removed; older mappings for those inputs are retained but disabled.
- **Remove row** and right-click **Remove row from Elka** hide an unwanted row and disable its MIDI control. Other controls keep running. Refreshing or restarting the application cannot immediately rediscover the removed row.
- **Restore removed (N)** restores removed rows on the current input with **Use** unchecked. Learned MIDI assignments are retained. **Save applications** remembers removals and restorations after restarting Elka.
- Right-click **Clear MIDI assignment** retains the previous ability to discard an assignment and return a connected app to automatic discovery.
- Profiles migrate from both earlier application previews. Strip/bus processing and its settings format are unchanged.

These row controls affect Elka's list. No Windows or VoiceMeeter list-reset operation is included: the documented Windows audio-session interfaces do not expose a command to delete another app's session, and resetting saved routing/volume settings would not be equivalent. See [Application MIDI Control](../Application-MIDI-Control.md) for details and test steps.

## Verification

- Visual Studio 2026 Debug and Release x64 builds with warnings treated as errors.
- 43,133 hardware-independent checks in each configuration, including removed-row persistence, restoration, per-endpoint identity, disabled legacy inputs and version-1/2 profile migration.
- Silent test-owned Windows audio integration covers removal while other controls remain active, source reservation, refresh, save/reload and restoration, alongside existing pickup/mute/recovery checks. No playback is started and no other application's volume is changed.
- The isolated UI host verifies the three input pages, context-menu removal, Remove row button, Refresh and Restore removed. Both restored rows remain unchecked.
- Physical MIDI and listening acceptance remains a user test. The currently running copy is not replaced automatically.

Unsigned portable Windows x64 build. Public packages contain no personal setup files or logs.
