# Elka MIDI Pickup 0.4.0-preview.2

**Local beta build for testing. Not published to GitHub.**

- Fixes the main window's wheel/resize repaint path: dropdowns are no longer resized on every scroll, and all child controls are redrawn after a real layout change. Scrolling over a closed dropdown no longer changes its selected device, target or tolerance.
- Application MIDI Control shows connected apps automatically with **Use** checkboxes. New apps start unchecked. The playback-endpoint and application dropdowns are removed.
- Input buttons follow the connected VoiceMeeter edition: Potato has VAIO, AUX, VAIO 3 and In 1–5; Banana has VAIO, AUX and In 1–3; Standard has VAIO and In 1–2. Missing Windows devices are disabled. Extension inputs still require your existing VoiceMeeter VAIO Extension routing.
- Closed apps and expired sessions leave Elka's visible list; learned assignments are retained for their return. **Refresh apps** releases Elka's cached sessions and rescans without restarting Windows audio or resetting volumes. Paused apps with live sessions remain listed.
- Adds rounded buttons in both windows. **Extra control** adds a separate volume/mute assignment for the selected app.
- Application profiles migrate from preview.1 while preserving exact endpoint and executable identities. The strip/bus pickup engine and settings format remain unchanged.

See [Application MIDI Control](../Application-MIDI-Control.md) for setup and test steps. Elka does not forcibly clear another program's mixer list.

## Verification

- Visual Studio 2026 Debug and Release x64 builds with warnings treated as errors.
- 43,120 hardware-independent checks in each configuration, including discovery defaults, route selection, closed/returning apps and version-1 profile migration.
- Silent test-owned Windows audio sessions verify discovery, process-exit cleanup, refresh, MIDI Learn, pickup, rapid reversals, external volume changes, mute, conflicts, connection recovery and saved mappings. No audio playback is started and no other application's volume is changed.
- Read-only inspection windows verify Strips, Buses and Settings scrolling, closed-dropdown stability, rounded buttons and the new application pages.
- Physical MIDI/listening acceptance for this update remains a user test. The running preview and its unsaved UI settings are not replaced automatically.

Unsigned portable Windows x64 build. Packages contain no personal setup files or logs.
