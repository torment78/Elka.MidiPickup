# 0.4.0-preview.4 — Combined audio reset

Application MIDI Control now has one **Reset audio** button. After administrator approval it restarts Windows Audio and restores its running dependent services, waits one second, then requests VoiceMeeter's audio engine restart.

MIDI output pauses throughout the sequence. Application session references are released, old MIDI motion is discarded, and previously active controls return armed for pickup using current levels. Saved mappings, routing and volume settings are retained. The button cannot start overlapping resets. Cancelling approval or failing the Windows restart skips the VoiceMeeter restart.

The existing **Refresh apps** button still only refreshes Elka's list without restarting audio.

## Validation

- Debug and Release x64 builds pass 43,144 regression checks each. Reset checks exercise the full one-second delay, single command issuance, duplicate clicks, simulated cancellation/failure, dependent-service order and partial-failure recovery without touching live services.
- Silent session integration passes in both configurations, covering pause, motion discard, re-arm, active-state restoration, retaining stopped controls, and failure behavior.
- The inspection window shows the new button in the top toolbar. An unelevated helper invocation was refused before touching any services.
- Live combined-button acceptance remains required. Earlier manual Windows Audio restarts cleared stale Spotify sessions on the development PC without changing the 104 checked VoiceMeeter settings.

## Live test

1. Play an application through a VoiceMeeter virtual input, then move it to another input. Record the current routing and levels.
2. Click **Reset audio** once and approve Windows elevation.
3. Check the status progresses through Windows Audio, the one-second wait, and VoiceMeeter's engine restart.
4. Confirm playback returns on the chosen input and the old entry clears. Check routing and levels.
5. Move a learned fader: it must wait for pickup. Controls that were stopped must remain stopped.
6. On a separate attempt, cancel elevation and confirm neither restart occurs.

This remains an unsigned local preview; broad device/application compatibility is not yet established.
