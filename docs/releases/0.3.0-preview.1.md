# Elka MIDI Pickup 0.3.0-preview.1

**Prerelease for testing — not stable.** This is the first public portable preview of Elka MIDI Pickup.

## What it does

Soft takeover for ordinary MIDI CC faders controlling VoiceMeeter: gains remain at their software position until the hardware reaches or crosses the target. External software gain changes re-arm the affected fader.

- Sixteen independent mappings across Strips and Buses, with MIDI Learn.
- Configurable top gain and pickup tolerance.
- Buffered MIDI processing and delayed-readback handling for rapid movements.
- Tray operation, optional Windows startup, tray launch and active startup.
- VoiceMeeter Potato custom display button 2 on supported versions.
- Dark UI, dedicated app/tray icon, and matching warm amber/rose artwork.
- Demo mode, saved setups, diagnostic counters and local logs.

## Downloads

- **Elka.MidiPickup-0.3.0-preview.1-win-x64-unsigned.zip** — extract to a writable folder and run Elka.MidiPickup.exe.
- **Elka.MidiPickup-0.3.0-preview.1-artwork.zip** — horizontal/vertical PNG masters, JPEG copies under 1 MB, app icon and prompt records.
- **SHA256SUMS.txt** — checksums for the downloadable ZIPs and the EXE inside the portable package.

The executable is **unsigned**. The release has no installer and bundles no MIDI driver or preview runtime. No personal setup/profile is included.

## Setup

Start VoiceMeeter, choose your **MIDI device**, connect both, learn one fader and select a target. Disable that fader's other direct mappings in VoiceMeeter/Bome, confirm this in Elka, then start pickup. See the included testing guide before enabling unattended startup.

This build controls VoiceMeeter through its Remote API. It **does not create a virtual MIDI port or pass through other MIDI messages**. Existing routes for other controls depend on your device's sharing support.

## Verification

Release and Debug x64 builds passed with **42,945 regression checks each**. The earlier pickup engine was tested successfully with an APC40 mkII and VoiceMeeter Potato. No live gains were changed during packaging.

Still needs physical acceptance testing: long sessions, multiple devices/editions, latest button-outline cleanup, Windows sign-in launch, delayed connections and unattended active startup. Please report the device, VoiceMeeter version, target, tolerance, steps to reproduce, and bottom status message.
