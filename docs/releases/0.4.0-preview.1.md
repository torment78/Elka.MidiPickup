# Elka MIDI Pickup 0.4.0-preview.1

**Local beta build for testing. Not yet published to GitHub.**

Adds **Application MIDI Control** as a separate warm-dark window. VAIO/AUX/VAIO 3 pages follow the connected VoiceMeeter edition. Discover connected audio applications, add rows dynamically, learn MIDI, and control per-application volume with pickup or mute with a button. Explicit two's-complement and offset-64 relative encoder modes are also available.

The strip/bus pickup algorithm and version-2 profile format remain unchanged. The preview shares the existing MIDI input, runs Windows audio-session work on a separate worker, and rejects conflicts with enabled strip/bus controls. Its mappings have their own file and always start stopped.

See [Application MIDI Control](../Application-MIDI-Control.md) for the test steps, volume curve, supported button/encoder modes, endpoint selection, and session-identity limitations. Physical controller/app acceptance remains pending.

This is an unsigned portable x64 preview. No driver, runtime, installer, automatic release publication or Windows upgrade is included. Public packages exclude personal profiles and logs.

## Verification

- Visual Studio 2026 Debug and Release x64 builds, warnings treated as errors.
- 43,107 hardware-independent checks in each configuration; the original 42,945 checks remain included.
- Isolated Windows audio-session integration in both configurations: session discovery, exact-identity writes, volume and mute readback, MIDI Learn, pickup and fast reversals, external edits, cross-feature source conflicts, explicit Stop, disconnection/reconnection, persistence and row removal.
- Preview window inspected with live session discovery in a read-only UI host; VAIO page switching and adding a separate mute row verified.
- No physical controller or listening acceptance claimed for the new application feature. Existing application gains and the running released Elka copy were left unchanged during testing.
