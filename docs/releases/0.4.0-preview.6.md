# 0.4.0-preview.6 — Installer and Application MIDI Control preview

This prerelease brings the tested local Application MIDI Control work to GitHub and adds an Inno Setup installer.

- Install under `Program Files\ElkaSoft\Elka MIDI Pickup`, with per-user settings in `%APPDATA%\ElkaSoft\Elka MIDI Pickup\Saves` and logs in `%LOCALAPPDATA%\ElkaSoft\Elka MIDI Pickup\Logs`.
- Upgrades and uninstall preserve saved setups. The portable ZIP keeps its existing files beside the EXE.
- Control individual application volume or mute on VAIO, AUX and VAIO 3. Learn absolute CC faders, note/CC mute buttons, or supported relative encoders.
- Saved offline application bindings remain visible in red on their original input. **Delete row** frees MIDI and saves the removal immediately.
- One **Reset audio** button restarts Windows Audio, waits one second, and requests VoiceMeeter's engine restart. Audio briefly stops; Windows requests administrator approval.
- Strip/bus pickup, tray operation, launch options and VoiceMeeter display button 2 remain available. Scrolling redraw fixes are included.

## Downloads

- **Setup EXE:** normal installation with Start-menu and optional desktop shortcuts.
- **Portable ZIP:** extract into a writable folder.
- **Artwork ZIP:** matching headers and icons.
- **SHA256SUMS.txt:** download checksums.

The app, installer and uninstaller are unsigned. This remains a **prerelease for testing**, with broad controller/application compatibility still requiring real hardware acceptance.

See [installation and migrating a portable setup](../Installation.md), [Application MIDI Control](../Application-MIDI-Control.md), and [testing](../Testing.md). Application control starts stopped and requires confirmation of routing each run.

## Validation

Debug/Release builds, storage and pickup regression checks, isolated silent audio-session integration, installer install/reinstall/uninstall checks, and download verification are recorded with the release. Installation testing does not restart Windows audio or change user routing.
