## Warm palette revision (final)

The user requested softer amber and pink/rose instead of the dominant blue. These edits produced the final masters, keeping the approved app icon.

### Horizontal edit

```text
Use case: lighting-weather
Asset type: horizontal Elka MIDI Pickup marketing header, retain exactly 1774 x 887 and existing layout.
Edit target: image 1, the existing MIDI Pickup horizontal banner.
Primary request: recolor and soften the surrounding banner to a warmer, calmer ElkaSoft style. The user finds the blue excessive and prefers amber with muted pink/rose. Replace navy/blue background with deep warm charcoal and subtle dark plum. Replace electric cyan/blue circuit traces, icon outline glow, underlines and flowing signal waves with soft warm amber, copper and dusty rose lights. Reduce glow intensity and visual busyness. Feature pill outlines should be amber, muted rose and warm cream instead of cyan/green/yellow. Keep clean white/cream readable text.
Invariants: preserve every word, placement, spacing and hierarchy: "Elka MIDI Pickup", "Soft takeover for VoiceMeeter", "PICKUP", "MIDI LEARN", "STRIPS + BUSES", "Windows x64  |  VoiceMeeter", "PRE-RELEASE", "by ElkaSoft". Preserve the original approved inner app icon unchanged: left cyan fader, right white fader and orange center dot on dark tile; only its surrounding decorative glow changes. For the footer wordmark use Elka amber and Soft muted rose.
Constraints: warm, smooth, refined, restrained luminosity; no dominant blue beyond the original cyan fader itself. No new elements, no extra text, no crop, no watermark. Opaque full-bleed banner.
```
